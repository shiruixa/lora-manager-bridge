⚙️ LoRA Manager Bridge 设置

配置 ComfyUI 服务器连接和扩展行为

服务器连接

ComfyUI 服务器的地址和端口。通常是 http://127.0.0.1:8188

网络代理

用于访问 CivitAI 的代理地址。扩展请求 localhost 的 ComfyUI 不经过代理。如果浏览器已配置系统代理，无需额外设置。

缓存

API 结果缓存时长，默认 30000 (30秒)。较大的值可减少 API 调用但数据可能不够实时。

LoRA Manager Bridge v1.0.0

在 Edge/Chrome 中加载此扩展: 访问 edge://extensions，启用"开发人员模式"，点击"加载解压缩的扩展"。
