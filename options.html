配置 ComfyUI 服务器连接和扩展行为

服务器连接

ComfyUI 服务器的地址和端口。通常是 http://127.0.0.1:8188

CivitAI API Key

检查中…

下载模型时 CivitAI 需要认证，没有这个 key 会返回 401，下载会失败。 key 只能填在 LoRA Manager 里——扩展没有权限代填。

位置：LoRA Manager 网页 → 右上角齿轮 → 第一个标签页 General → 语言选择器正下方（很靠上，不用往下翻很多）→ 找到 CivitAI API Key → 点 Set up 粘贴保存。

key 在 civitai.com → 账号设置 → API Keys 生成，权限只需 Models 的 Read。

下载

下载由 LoRA Manager 自己完成，文件放入对应类型的模型目录 （LoRA → loras、Checkpoint → checkpoints、Embedding → embeddings）。 具体子目录遵循你在 LoRA Manager 里的「下载路径模板」设置——扩展不覆盖它的配置， 因此装上即可用，无需改 ComfyUI 启动参数或任何设置。

缓存

API 结果缓存时长，默认 30000 (30秒)。较大的值可减少 API 调用但数据可能不够实时。
